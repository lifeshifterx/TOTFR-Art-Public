# TOTFR-Art-Public

Public delivery repository for **PLAYER_SAFE** Tales of the Forgotten Realms artwork used by Notion.

Only approved player-safe image binaries may be published under `assets/`. Every asset must be listed in `public-manifest.json` with an exact SHA-256 and byte size. DM/future/spoiler material, source prompts, control-plane documents, deployment evidence, archives, and staging content are prohibited.
